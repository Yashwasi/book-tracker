📘 About My Book Tracker

My Book Tracker is a cozy web app for readers to search, save, and organize books they love. Whether you're a casual reader or a full-on bookworm, this platform helps you build your own personal bookshelf.

Hi, I’m Yashwasi — a third-year Computer Science student who built this project to learn full stack development. I wanted it to be functional, pretty, and fun to use!

✨ Features:

  • 📚 Add books to your shelf
  • 🔍 Search books using the Google Books API
  • 🧾 View authors, genres, and summaries

🛠️ Built With:

  • 🐍 Flask (Python)
  • 🗃️ SQLite
  • 🎨 HTML & CSS
  • 🌐 Google Books API

This is just the beginning! I plan to keep improving the app — adding book ratings, categories, and even public reading lists.

Thanks for visiting! 📖
